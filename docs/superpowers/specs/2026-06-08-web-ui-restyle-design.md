# NewBee Web 前端 UI/UX 高级化重设 — 设计方案

日期：2026-06-08
范围：`apps/web`（React + Vite，舞台式对话共创界面）
状态：已与用户确认，待转实现计划

## 目标

把现有"深色科技仪表盘"风格的前端，重设为**可爱但克制的精致暖调**界面：亲和、有温度、有辨识度，避免通用 AI 风格（generic AI slop）。可爱来自圆角、柔和质感、形象存在感和微动效，而非高饱和配色或夸张弹跳。

确定的三个关键决策：
- 方向：活泼游戏化 → 收敛为**克制版暖调**
- 气质：可爱吉祥物风（围绕 NewBee 小蜜蜂形象），但**降甜度、加留白**
- 范围：**整体重设**（含布局/组件结构与样式），追求最佳效果

## 一、美学基调 & 配色系统

围绕中央 Avatar（NewBee 小蜜蜂）打造一个温暖、精致、亲和的"创作小屋"。气质参考 Linear/Notion 的克制，但底色是暖的、有温度，不冷。可爱体现在细节与微动效。

全部颜色抽成 CSS 变量（design token），集中在 `styles.css` 顶部 `:root`。

配色盘（克制暖调）：
- 背景：温白/米白 `#FAF8F4`，极淡暖灰过渡 + 几乎察觉不到的噪点纹理（避免塑料纯色感）
- 主色（蜂蜜琥珀）：`#E8943A`，仅用于 CTA、选中态、关键强调，大面积留白
- 方向 A：低饱和青灰 `#5B8A8A`（tag/描边点缀）
- 方向 B：低饱和陶土粉 `#C77B6B`（tag/描边点缀）
- 文字主：暖墨 `#3A3530`；次要：`#8A8175`
- 卡片/气泡：白底 `#FFFFFF` + 1px 暖灰描边 `#ECE6DC` + 克制柔和投影；中等圆角 14–16px

相对原稿的收敛：降饱和、减渐变、减投影厚度、加留白。去掉所有锐利边框与冷色。

## 二、字体与排版

放弃系统默认字（generic 信号）。全部走 CSS 变量：`--font-display` / `--font-body` / `--font-mono`。

- 显示字/标题：圆润有亲和力但不幼稚的无衬线 —— 英文 **Quicksand** 或 **Baloo 2**；中文搭配圆润黑体（阿里巴巴普惠体 / HarmonyOS Sans）。
- 正文：高可读中性无衬线 —— 英文 **Inter Tight** / **DM Sans**；中文 PingFang / HarmonyOS Sans 常规字重。
- 等宽（DSL/JSON）：**JetBrains Mono** / **IBM Plex Mono**。

外部字体走 Google Fonts / 本地引入；提供系统圆体兜底（离线/性能降级）。

排版节奏：
- 建立清晰 type scale（约 11/13/15/18/24/32），拉开标题与正文层级对比。
- 正文行高 1.6，标题略紧 1.25；中文标题加少量 letter-spacing。
- 留白优先：加大卡片内边距与区块间距，中央 Avatar 更多呼吸空间。

中文为主：英文显示字 + 中文圆润黑体搭配。

## 三、布局与空间构图

保留现有三段式骨架（顶部上下文流 + 中央舞台 + 底部输入），重点重新分配空间与视觉重心，从"仪表盘"变"舞台"。

- 整体框架：内容收进**居中容器**（max-width ~1100px），两侧留暖白边距，不再贴边。区块间用留白和极淡分隔代替硬 `1px` 边框。
- 顶部上下文流：弱化为更轻的"历史条" —— 收窄高度、半透明、降低存在感（它是上下文不是主角）。气泡改圆润对话泡，暖色区分用户/NewBee。
- 中央舞台：Avatar 为绝对焦点，给更大呼吸空间 + 一束柔和暖光晕（径向渐变，替换原冷色 radial）；形象底部加柔和落地投影/光台，避免浮空感。左右选项气泡更贴近形象，像它递出两个选择（可选极细引导线/小尾巴指向形象）。
- 底部输入：圆润有厚度的悬浮卡片（pill/大圆角），聚焦时主色描边轻微辉光；发送按钮用主色蜂蜜琥珀。
- 结束态成果面板：GDD / 最终输出从"代码框"升级为有层次的卡片，标题区配小图标徽章，圆角与留白与整体一致。
- 响应式：保留现有 860px 断点单列堆叠逻辑，调好间距。

## 四、动效与质感细节

原则：少而精、自然有弹性；一次精心编排的入场胜过满屏散落微动效。

质感：
- 暖白背景叠极淡噪点纹理（CSS 生成或微小 base64）。
- 卡片/气泡：白底 + 暖灰细描边 + 柔和多层投影（纸感深度）。
- Avatar 暖光晕：径向渐变 + 轻微呼吸（幅度极小，可被 reduced-motion 关闭）。

核心动效：
- 选项气泡入场：保留 `popRise` 思路，调成更克制缓动（轻微上浮 + 淡入，去掉夸张 `scale(.6)`，改柔和回弹）；左右错峰 stagger 保留。
- 选中反馈：去掉夸张 `scale(1.06)` 脉冲，改为主色描边渐亮 + 轻微抬升 + 柔和外发光；未选中的优雅淡出收缩。
- 打字机：保留现有 `useTypewriter` 逻辑与光标，光标颜色换主色。
- 输入框聚焦：边框主色渐入 + 极淡辉光，平滑过渡。
- 首次加载：标题、Avatar、输入卡做一次轻量 staggered 入场（依次淡入上浮），给"舞台拉开"的仪式感。

无障碍：保留并扩展现有 `prefers-reduced-motion` 降级（呼吸光、入场动画全部关闭）。

实现约束：
- 纯 CSS 动效为主，不引入 Motion 等新依赖（保持轻量）。
- 所有颜色/字体/圆角/间距/阴影/动效时长抽成 design token（CSS 变量），集中在 `styles.css` `:root`。
