# GDD 完整度门

缺任一项必填 → 不合格，回到对应阶段补问，**不得带病写盘**。

## 必填章节

| 必填项 | 合格长什么样 | 缺了回哪 |
|---|---|---|
| 一句话 Pitch / 核心体验陈述 | 能让陌生人立刻听懂「这游戏关于什么、玩完是什么感觉」 | 火花 / 核心体验 |
| 核心情感（主 / 禁止） | 主情感明确；至少标出一种**不要**的情绪（避免做成四不像） | 核心体验 |
| 核心幻想 / 玩家身份 | 玩家幻想成为谁、在做什么 | 核心体验 / 世界 |
| 核心游戏循环（微 / 中 / 宏） | 至少有「头几秒在做什么」；5 分钟、30 分钟/长线能写则写，写不出就标明「本游戏是短单局，无长线」 | 核心循环 |
| 核心机制清单（按优先级） | ≥2 条玩家反复做的事，有主次 | 核心循环 |
| 失败 / 胜利规则 | 怎样算赢、失误有什么麻烦 | 核心循环 |
| 奖励节奏 | 玩家怎么知道自己做得好 | 核心循环 / 心流 |
| 美学 / 手感 / 高光 | 画面声音感觉 + 至少一次「屏幕怎么夸奖玩家」或手感隐喻 | 美学 |
| 六类关键词池 | 玩法 / 情绪 / 世界观 / 视觉 / 叙事 / 玩家动机；每类 ≥5，尽量 ≥10 | 贯穿，收敛时补齐 |
| 差异化亮点 + 参考作品 | 和同类最大不同；借鉴什么、**刻意避开**什么 | 火花 / 收敛 |
| 游戏宪法 | 已确认的不可漂移项，至少含核心幻想与核心循环 | 凡确认即锁 |

## 条件必填

创意一旦涉及，对应章节升为必填，否则可写「本游戏无……，不单列」：

- 多关卡 / 关卡结构
- Boss
- 养成 / 经济 / 长线系统
- 多人同局

## 呈现与资产

用生活化语言问清并写入「呈现与资产」：

- 在哪玩：电脑 / 手机 / 网页
- 画面是平面还是能转视角的立体
- 手机的话横屏还是竖屏
- 自己玩还是要和别人一起
- 需要哪些画面与声音（插画、音乐音效、像素、横版卷轴等）

缺这些也可以先写草稿，但**定稿前应补齐**——它们决定游戏长什么样。

## 创新性自检（写盘前必过）

- [ ] **体验**：每个核心系统都能回答「玩家在想什么 / 哪个瞬间最满足 / 去掉它核心体验还在吗」
- [ ] **趣味**：每个核心机制至少满足「意外 / 掌控感 / 进步感 / 社交」中的两项
- [ ] **系统生态**：无孤立系统、无只会膨胀的正反馈、无玩家看不懂的黑箱
- [ ] **规模**：游戏写成当前就能玩完的形态
- [ ] **防漂移**：确认项已入宪法；全文用语与宪法一致

任一项不过 → 回环补问，不写盘。

## 审计时怎么判断「不合格」

用户第一条消息或已有 `{游戏名}-gdd.md`（或旧名 `gdd.md`）出现下列情况，视为未达完整 GDD，必须先征得同意再澄清：

- 只有类型词（「做个塔防」「做个类似 XX」）没有核心体验
- 有世界观没有玩家反复做的那件事
- 有玩法没有失败/胜利
- 章节标题齐全但内容是空话 / 「待定」 / 明显套模板
- 宪法缺失，或后文已经和前文确认过的幻想冲突
