# GDD Markdown 模板

把花括号替换成对话里确认过的内容。删掉提示性注释。文件名：`{游戏名}-gdd.md`（例：`八爪鱼迪斯科-gdd.md`），有 `docs/` 则放 `docs/`。

```markdown
# {暂定游戏名}

> 一句话 Pitch：{这是一个关于……的游戏。}

## 游戏宪法

> 不可漂移项。后续任何改动需明确确认。

- 核心幻想：{…}
- 核心循环：{…}
- 美术规则：{…}
- 内容边界：{…}
- 呈现边界：{…}
- {其他已确认项}

## 1. What · 这是什么游戏

### 核心体验陈述
{让玩家感受到＿＿。朋友玩完会用哪三个词形容。}

### 核心情感
- 主情感：{…}
- 禁止情感：{明确不要做成什么样；没聊过就删这一行}

### 核心幻想 / 玩家身份
{玩家幻想成为谁，在什么处境里做什么。身份已包含在幻想里就不要再拼一段。}

### 差异化亮点
{和同类作品最大的不同，一句话能说清。}

### 参考作品
- 借鉴：{作品 + 借鉴的是哪一点；没有就删这一行}
- 刻意避开：{作品或做法 + 为什么避开；没聊过就删这一行}

## 2. How · 怎么玩

### 核心动作
{最重要、最频繁的一件事。}

### 核心游戏循环
- 微循环（约 30 秒 / 头几秒）：{行动 → 反馈 → 奖励 → 下一个行动}
- 中循环（约 5 分钟）：{… 或注明「短单局，中循环即一局」}
- 宏循环（约 30 分钟 / 长线）：{… 或注明「本游戏无长线」}
- 长线：{和宏循环不是同一件事时才写，例如买下整条街 / 反复复盘通关}

### 核心机制（按优先级）
1. {主机制}
2. {次机制}
3. {可选项，总共 3–6 条，不要把同一玩法和物件名各写一遍}

### 奖励节奏
{玩家怎么知道自己做得好；短馈与稍长的奖励分别是什么。}

## 3. Win · Lose

- 胜利：{怎样算赢 / 怎样算一局漂亮}
- 失败：{失误的麻烦：掉血 / 直接重来 / 扣时间 / 其他}
- 重玩动机：{「就差一点马上再来」还是「去变强再来」}

## 4. 世界、叙事与美学

### 世界与情境
{发生在哪、玩家扮演谁、冲突是什么。可很小。}

### 叙事
{玩家经历怎样的旅程；没有剧情则写「几乎无剧情，体验靠氛围与循环」。}

### 视听氛围
{画面与声音给人的感觉；用比喻写。}

### 手感
{操作手感隐喻，如「切豆腐」或「拉满弓」。}

### 高光时刻（Juice）
- {完成超厉害操作时，屏幕/声音怎么夸奖玩家。一条一个瞬间，不要顿号墙}

## 5. 内容

{关卡 / 敌人 / 道具 / 事件等可生产内容的结构。没有则写「内容即核心循环本身，靠难度变化重复」。}

若有多关卡 / Boss / 养成，在此展开；没有就明确不单列。

### 关键词池

只写短词。没有短词就删掉整节，不要把章节正文用顿号切进来。

- **玩法**：{词、词、…}
- **情绪**：{…}
- **世界观**：{…}
- **视觉**：{…}
- **叙事**：{…}
- **玩家动机**：{…}

## 6. 呈现与资产

- 在哪玩：{电脑 / 手机 / 网页}
- 画面维度：{平面 / 有立体空间}
- 屏幕方向：{横屏 / 竖屏 / 不限}
- 人数：{自己玩 / 要和别人一起}
- 主要资产：{插画、角色、场景、UI、音乐、音效……需要哪些}

## 7. 难度与心流

- 怎么上强度：{…}
- 前几分钟玩家应感到：{…}
- 可能的疲劳点与缓解：{…}
```
